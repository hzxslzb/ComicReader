# ComicReader 1.3.3 · 阅读能耗优化与无打扰切章

发布日期：2026-10-27。versionCode：9。Android 8.0+。

## 本次更新

- **增量预加载**：保留后续窗口内已经完成或正在进行的图片，只补新增页，减少翻页时反复取消、重建预取。
- **纯磁盘预取**：预加载只缓存原始编码图片，命中缓存直接跳过，不再为预取执行 bitmap 解码；真正显示时正常解码。
- **按显示尺寸加载**：图片按实际控件宽度选择稳定分辨率档位，纵向缩放稳定后再调整，最高解码宽度保持 2400；保留 50%–400% 缩放及不遮挡漫画的复位按钮。
- **后台暂停预加载**：应用不可见时停止阅读预取，返回后恢复；用户主动启动的下载任务不受影响。
- **切章不再弹出控制框**：同一本漫画连续切章保持工具栏显隐；隐藏状态的章节加载过程中也不临时显示返回框。轻点图片仍能主动显示控件。

预加载开关、3／4／5 页、仅 Wi-Fi、三种阅读方向、宽屏双页、独立阅读历史和下载离线功能继续保留，原有偏好不被重置。

## 安装与数据保留

下载 `ComicReader-1.3.3.apk`，**直接覆盖安装，不要先卸载或清除应用数据**。

沿用包名 `com.arnolee.moye`、原签名证书、数据库版本 1 和下载目录。已在模拟器验证正式签名 1.3.2 → 1.3.3：覆盖前后 10 个数据文件 SHA-256 一致，启动后收藏、逐章页码、设置、下载任务和图片保持完整。升级后断网也已验证可恢复原章节、页码并阅读离线图片。自行换签名的安装包不能覆盖官方包。

Release 同时提供源代码 ZIP 与 `SHA256SUMS.txt`。签名私钥不包含在源码或附件中。

## 验证与范围

- 35 项 JVM 测试、全部 11 项设备用例通过，涵盖真实站点搜索发现、阅读切章、下载离线、Fold7 比例适配、缩放与预加载策略。
- 受控窗口测试：连续前进 10 页、预取 5 页且每轮完成时，15 张不同图片只进入 15 次预取任务；旧调度会进入 55 次预取流程。这不是网络下载次数或节电百分比。
- 追加验证 LTR、RTL、上下滚动及宽屏双页：末页切章后控件继续隐藏，重建 Activity 后状态保留。

- Debug / Release 构建与签名校验通过；Lint 无错误。
