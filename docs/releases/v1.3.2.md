# ComicReader 1.3.2 · 预加载偏好与缩小阅读

## 预加载设置

主设置页和阅读设置面板均新增：

- **预加载开关**：随时启用或关闭。
- **提前加载 3／4／5 页**：接近章节末尾时包含下一章。
- **仅 Wi-Fi 下预加载**：关闭此选项后，移动网络也可预加载。

默认开启预加载、提前 5 页、仅使用 Wi-Fi。设置自动保存并立即生效。关闭预加载或断开 Wi-Fi 时停止后台预取，当前页及主动切章仍可正常联网；已经缓存的图片仍可使用。

## 上下滚动支持缩小

- 双指缩放范围扩展为 **50%–400%**，支持缩到默认尺寸以下。
- 缩小时图片居中，仍可上下滚动；放大后支持横向拖动。
- 放大和缩小后都显示“恢复默认”，复位至 100%，按钮在漫画区域外。
- 非默认倍率时双击恢复默认；默认倍率时双击放大。

## 升级

下载 `ComicReader-1.3.2.apk` 直接覆盖旧版，不要先卸载。包名、正式签名、数据库及下载目录保持不变，书架、下载和阅读历史继续保留。versionCode 为 8。

预加载属于临时缓存，不替代完整离线下载。允许非 Wi-Fi 预加载后会使用移动数据。更新附带源码包与 SHA-256 校验文件。
