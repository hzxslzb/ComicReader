# ComicReader 1.3.4 · 双向切章与应用内更新

versionCode：10。Android 8.0+。

## 章首也能滑动切章

到达本章第一张图片的开头并停稳后，再做一次“上一页”手势，返回上一章末页：

- 上下滚动：向下拉。
- 普通翻页：向右滑。
- 日漫模式：向左滑。

支持宽屏双页。滑回章首的那次动作不会顺带切章，放大横拖、双指操作或没有上一章时不会误切。章末进入下一章继续保留，双向切章均保持工具栏显隐。

## 应用内检查、下载和安装更新

在 **设置 → 应用更新** 手动检查最新 GitHub 正式版本，查看公告后点击“下载并安装”。首次需在系统设置允许 ComicReader 安装应用，之后在系统安装页面确认。默认启动时每天最多检查一次，可关闭；不自动下载，也不在阅读时弹出更新公告。

下载显示进度，可取消／重试。完整下载经 SHA-256、包名、签名及递增版本号校验后才交给系统安装；已完成的包可在应用重启后继续安装，未完成的下载需重新开始。网络错误或 GitHub 限流可稍后重试。

**1.3.3 及更早版本没有应用内更新入口，请先下载本次 APK 手动覆盖安装一次；以后可在应用内更新。**

## 数据保留与验证

直接安装 `ComicReader-1.3.4.apk`，**不要先卸载或清除数据**。包名、官方签名证书、数据库版本和离线目录均保持不变；新更新模块的数据与原书库隔离。
