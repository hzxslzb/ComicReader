# ComicReader 1.3.0 · 末页切章与独立阅读记录

ComicReader 首次公开发布。它是一款面向 Android 8.0+ 的原生漫画阅读器，支持全站搜索、书架、在线阅读、下载与离线阅读、深浅主题，以及折叠屏自适应布局。

## 本次更新

- **末页再滑，进入下一章**：读到最后一页后，再主动向下一页方向滑动一次即可切章。支持纵向上滑、普通模式左滑、日漫模式右滑与宽屏双页。
- **每本漫画单独记住进度**：分别保存章节及页码；详情页“本书阅读记录”可查看各章最后读到的位置和时间，点选继续。
- **避免误切章**：到达末页的同一次手势、惯性滚动、双指缩放和放大横拖不会触发。没有下一章时停留原处。
- 下一章已有历史时从断点继续，没有历史时从第一页开始；修正同一时间戳下最近阅读章节的排序。

## 包含的功能

- 首页精选与热门栏目、全部分类、最近更新、漫画大全、排行榜、关键词搜索与分页。
- 收藏书架、最近阅读、目录与上一章／下一章。
- 上下滚动、左右翻页及日漫模式；双指／双击缩放，连续滚动支持 1–4 倍。独立底栏的“恢复默认”不遮挡漫画。
- 单章及批量下载、暂停、继续、失败重试、断网离线阅读。
- 浅色、深色、跟随系统；Fold7 比例适配、宽屏分栏及自动双页。
- 原生界面不加载网页广告或执行远程脚本。
