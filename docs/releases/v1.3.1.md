# ComicReader 1.3.1 · 切章加载修复与 5 页预加载

本次修复章节切换时的加载状态竞争，并减少翻页和跨章等待。

## 修复

- 旧章节请求结束时，不再错误关闭新章节的加载状态或覆盖新请求的错误信息。针对这一时序的设备测试在 1.3.0 失败、修复版通过。
- 章节请求遇到连接中断、超时和部分服务器临时错误时有限重试，最多 3 次。403 拒绝访问、404 不存在、429 限流及证书校验错误不反复重试。
- 请求可随阅读任务取消；被取消的图片请求不再继续切换图片服务器。

## 新增预加载

- 自动预加载当前位置后续 **5 页**，逐张加载。
- 接近章末时提前请求下一章，并按其已有阅读断点预加载后续图片；未读过则从第一页开始。
- 前台切章复用正在进行的章节预取请求，图片与正常阅读共用磁盘缓存。
- 预加载不写入阅读历史，不创建永久下载任务；退出阅读停止预取，缓存仍有 150 MB 上限。
- 移动网络下也会消耗流量。临时预加载不能代替整章离线下载。

## 安装

下载 **ComicReader-1.3.1.apk**，直接覆盖现有版本，不要先卸载。versionCode 为 7；包名、正式签名、数据库版本和下载目录保持不变。

Release 同时提供对应源码包和 `SHA256SUMS.txt`。书架、阅读记录和离线下载继续保留。

## 验证范围

旧版与修复版的同一请求竞争回归、真实漫画末页滑动到下一章并显示首图、5 页预加载后断网全尺寸显示均已验证。26 项 JVM 测试、7 项设备测试通过，Lint 为 0 errors、15 项既有 warnings。完整回归记录见仓库 `TESTING.md`。

真实数据源验证使用 Android 模拟器；未连接用户手机，因此不能确认其网络环境下所有异常均由同一原因造成。
