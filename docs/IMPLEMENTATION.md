# ComicReader 1.3.2

原生 Android 漫画阅读器，面向漫画柜移动站。米白／松绿浅色与深墨夜间主题，原生界面不加载网页广告或执行远程脚本。

## 品牌与图标

应用名称统一为 ComicReader；桌面、应用内书架／关于页面和下载通知同步更新。
图标采用构成主义风格，以红、黑、米白几何色块和斜向构图抽象表现飞行漫画书。
原始画稿位于 `../assets/branding/comicreader-flying-manga.png`，生成方式及最终提示词见同目录 `GENERATION.md`。
Android 8.0+ 使用 adaptive icon，由系统适配圆形和圆角矩形遮罩；通知栏另用清晰的单色书本符号。
包名及正式签名沿用原版本，可覆盖升级并保留书架、下载和历史记录。

## 1.3.2 预加载策略与缩小

`PreloadPreferences` 保存开关、3–5 页范围及 Wi-Fi 限制，默认开启、5 页、仅 Wi-Fi。`ReaderNetwork` 观察默认网络变化；默认网络具备 Wi-Fi transport 和 Internet capability 时允许 Wi-Fi 预取，无法确认 Wi-Fi 的连接保守暂停。

设置变更及网络变化会取消并按策略重建预取任务，每张图片和章节预取发出前再次检查网络。章节加载器以等待者计数管理共享请求：最后一个预取等待者离开时取消底层请求；前台已接管的请求继续，避免开关预加载导致正常阅读失败。

连续滚动允许 0.5–4 倍布局缩放，小于 1 倍横向位移归零并居中；任何非默认倍率都显示位于视口外的复位栏。设置在 SharedPreferences 内持久化，数据库结构不变。

## 1.3.1 加载与预取

- 阅读请求带递增代次，旧请求的失败及收尾不能改变新章节的状态。
- `ReaderChapterLoader` 合并前台与预取的同章请求，保存最多 3 章、2 分钟的新鲜清单；永久下载优先，网络失败可回退已保存清单。
- `ReaderPreloadWindow` 限定向后 5 页；接近章末立即启动下一章清单请求，图片逐张预取，按下一章的已有断点开始。
- `ReaderImages` 让预取与显示使用相同磁盘缓存键，预取仅解码缩略尺寸且不保留内存位图，显示时使用完整缓存图片重新解码。
- 预取不写入阅读进度、不创建下载任务；退出阅读取消未完成工作。图片缓存仍受 150 MB 上限约束。
- 章节请求可取消，连接类错误和 408/500/502/503/504 最多请求 3 次并退避；403/404/429 和证书校验失败不重试。

## 已实现

- 发现首页：原站精选横幅、热门连载、经典完结、漫迷推荐、最新上架，支持左右浏览和换一批。
- 全部分类：动态读取原站目前 52 个入口（全部／连载／完结、6 地区、5 读者群、38 题材）。
- 最近更新、漫画大全、排行榜：真实数据、加载更多、更新日期、排行名次及手动刷新。
- 漫画大全按分类及添加时间／更新时间／浏览次数排序，后续分页保留筛选条件。
- 关键词搜索、分页、搜索历史，以及漫画柜链接打开。
- 漫画简介和章节目录，收藏书架、最近阅读、继续阅读。
- 上下滚动、左右翻页、日漫右到左翻页，双击／双指缩放、页码滑动跳转。
- 上下滚动支持 0.5–4 倍连续布局缩放，放大后仍可纵向滚动，并可横向拖动；底部独立区域显示比例与“恢复默认”，复位尺寸和横向位置，不叠在漫画上。隐藏工具栏时恢复按钮仍可操作，页码提示也移至漫画区域之外。
- 阅读器目录、上一章／下一章；每部漫画和每章分别保存阅读位置，重启后可继续。
- 到达章节末尾后，再主动按下一页方向滑动一次可进入下一章：纵向上滑、普通翻页左滑、日漫右滑，展开屏双页同样适用。到达末页的那次手势、惯性滚动、双指动作和放大后的横向拖动不会触发切章。
- 漫画详情新增“本书阅读记录”，只显示当前漫画各章最近读到的页码和时间，点击继续该章；书架“最近阅读”继续按漫画分别保留最近章节。进入下一章沿用该章已有的阅读断点，没有断点时从第一页开始。
- 单章、多选章节和整本队列下载，暂停、继续、失败重试、前台进度通知。
- 逐页原子保存并验证图片格式；完成下载的章节断网可读。
- 浅色、深色、跟随系统；阅读器里也可切换主题和阅读方向。
- 临时图片缓存上限 150 MB，独立于永久离线章节；删除下载保留收藏与进度。

## Galaxy Z Fold7 与可变窗口

参考三星官方规格：外屏 1080×2520（9:21），展开内屏竖向 1968×2184（约 9:10）。
来源：https://news.samsung.com/global/samsung-galaxy-z-fold7-raising-the-bar-for-smartphones

应用按当前窗口的 dp 宽高适配，不锁定机型、分辨率或旋转方向，也支持分屏与显示缩放：

- 小于 600 dp：底部导航；600 dp 起：侧边导航。
- 书架采用自适应封面网格；搜索和下载在空间充足时排列为两列或更多列。
- 发现页面沿用可变窗口布局：窄屏单列、展开屏多列；分类自动换行，顶部栏目可横向滚动。页面切换和 Activity 重建保留本次浏览会话的筛选、已加载列表和滚动状态。
- 详情在宽度 ≥ 600 dp 且高度 ≥ 480 dp 时左右分栏；较窄或较矮窗口使用纵向布局。
- 翻页模式在宽度 ≥ 600 dp、高度 ≥ 360 dp 时可自动双页，首张封面单独展示；日漫模式反转同一组中的左右页序。
- “宽屏自动双页”可以在设置或阅读设置中关闭；上下滚动模式保持单列，列宽上限 720 dp。
- 阅读进度始终以原始单页索引保存，展开／收起时不会把第二页错误记为该组第一页。
- 横向低高度窗口压缩阅读工具栏；所有页面尊重状态栏、导航栏及系统安全区域。
- Activity 正常响应系统重建，启动链接和通知入口不会在旋转／展开时重复执行。

## 构建

需要 JDK 17、Android SDK 35（minSdk 26，Android 8.0+）。

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest
./gradlew :app:assembleRelease
```

Release 使用本项目单独生成的签名，不使用公共 debug 签名。`signing/moye-release.jks` 和 `signing.properties` 仅保存在本机，已加入忽略列表；请备份它们，后续版本需使用相同密钥才能覆盖升级。不要公开这两个文件。没有签名配置时可构建 debug 版本。Debug 使用独立包名 `com.arnolee.moye.debug`，不会覆盖已安装的正式版。

## 实现结构

| 文件 | 职责 |
|---|---|
| `MangaSource.kt` | HTTP 请求、HTML 解析、受限的压缩字典／章节解码；不执行远程 JS |
| `DiscoverSource.kt` | 首页栏目、全部分类、列表及榜单解析，按原站 GET 参数分页 |
| `DiscoverState.kt` | 按分类／排序隔离浏览状态，保留结果、分页元数据及错误重试 |
| `DiscoverScreen.kt` | 发现首页、分类、更新、大全、排行榜的原生自适应界面 |
| `LibraryStore.kt` | SQLite 数据库、收藏、逐章进度、任务状态、下载文件 |
| `DownloadService.kt` | dataSync 前台服务、队列、暂停恢复、重试、图片校验 |
| `AppViewModel.kt` | 页面状态、请求取消、搜索、阅读和下载操作 |
| `Screens.kt` | 书架、搜索、详情、下载和设置界面 |
| `ReaderScreen.kt` | 阅读模式、缩放、页码与章节导航、生命周期进度保存 |
| `ReaderZoom.kt` | 缩放范围与边界、缩放锚点、区分双指缩放／单指横拖／纵向滚动 |
| `ChapterSwipe.kt` | 仅识别在章节末尾开始的新单指滑动，按阅读方向切下一章 |
| `AdaptiveLayout.kt` | 窗口断点、网格条目与阅读双页映射 |
| `DetailScreen.kt` | 单列／双栏漫画详情与批量章节操作 |
| `Theme.kt` | Material 3 浅／深色主题 |

Kotlin + Compose + OkHttp + Jsoup + Coil；SQLiteOpenHelper 保存关系数据，SharedPreferences 保存少量偏好。无需自建服务器、账户或登录；应用不集成广告及分析 SDK。

## 数据与恢复

- 漫画详情、章节目录、图片清单及阅读历史保存在私有数据库。
- 离线图片保存在 `files/chapters/<book>/<chapter>/<page>.img`，扩展名与格式无关，内容按原始响应保存。
- 下载文件先写入独立 `.part`，验证可解码且完成刷盘后再原子重命名。
- 暂停／中断以完整图片为恢复单位；不会重新下载已经完成的页，单张未完成图片会重新请求。
- 进程被结束后任务保留，重新打开 App 可在下载页点“继续”。后台服务受 Android 系统运行时间限制，不能承诺永久后台运行。
- 目前没有跨设备同步或导入导出，卸载应用会删除本地数据。升级安装保留数据。
- 本项目正式 APK 使用相同包名和签名；直接覆盖安装，不要先卸载或清除应用数据。1.3.0 仍沿用数据库版本 1 和原下载目录，不进行清库或重建。

## 数据源范围

当前适配 `https://m.manhuagui.com`。站点没有对本应用提供稳定 API 承诺，未来 HTML、图片签名或访问规则变化可能需要更新解析器。错误页面提供重试，不自动绕过验证码或登录。对于章节中的版权页、宣传页及图片水印，按原始内容展示。

发现数据直接来自 `/`、`/list/`、`/update/`、`/rank/`。最近更新与排行榜当前各提供 5 页、100 本，应用遵循站点的分页上限；漫画大全按站点返回的总页数继续加载。地区、题材、读者群与连载状态采用原站单分类筛选，不拼接站点不支持的交叉条件。列表和首页会话缓存在内存中，重新启动进程会重新获取，离线阅读仍使用独立的永久下载。

## 测试

`SourceTest` 使用固定 HTML 样本测试搜索、章节顺序、压缩图片清单、分页片段和错误数据。
`DiscoverSourceTest` 使用原站样本验证全部分类、首页所有批次、排行榜 AJAX 名次、排序分页地址及错误页面拒绝。
`DiscoverFlowTest` 在联网模拟器中验证首页换批、52 分类、分类排序后的翻页、更新与榜单、详情返回、折叠窗口和重建，以及断网刷新保留旧结果和联网重试。
`LibraryTest` 验证数据库重开后的进度、收藏与下载状态恢复，以及删除下载不影响历史。
`ReadingFlowTest` 是有网络依赖的真实数据源集成测试，会使用 Android 模拟器关闭再开启 Wi-Fi／移动网络，验证下载后的本地阅读，请只在测试模拟器运行。

`AdaptiveTest` 验证单双页映射、奇偶页数和窗口断点；`FoldLayoutTest` 通过调整模拟器实际显示尺寸验证外屏／内屏／横向／分屏、RTL 页序、显示缩放、Activity 重建和精确页码保留。测试样本仅位于独立 Debug 应用中，不随正式 APK 发布。

`ReaderZoomTest` 验证缩放边界、横向位移约束和锚点换算；`ReaderZoomFlowTest` 注入真实双指捏合、双击、上下滑动、横向拖动和恢复按钮操作，覆盖外屏／内屏，并断言按钮区域与漫画视口没有重叠。

`ChapterSwipeTest` 验证方向、距离阈值与交叉轴排除；`ChapterAdvanceTest` 验证末页新手势才切章、LTR／RTL／连续滚动／双页、放大横拖不切章、最终章边界、本书记录点击续读与重建。`LibraryTest` 还验证多本漫画使用相同章节 ID 或相同时间戳时，记录仍独立且最后阅读章节确定。
