# 10 · 自适应布局与视觉设计

[返回文档中心](README.md) · 关联：[阅读器](06-阅读器与手势实现.md)、[测试](13-测试体系与验收.md)

## 1. 适配原则

当前实现按 **实际窗口约束** 布局，不通过 Samsung 型号或物理屏幕分辨率选择分支。展开、收起、旋转、多窗口和显示缩放都可能改变可用 dp；同一部手机不应始终固定为某个布局。

入口：[AdaptiveLayout.kt](../app/src/main/java/com/arnolee/moye/AdaptiveLayout.kt)、[Screens.kt](../app/src/main/java/com/arnolee/moye/Screens.kt)、[DetailScreen.kt](../app/src/main/java/com/arnolee/moye/DetailScreen.kt)、[ReaderScreen.kt](../app/src/main/java/com/arnolee/moye/ReaderScreen.kt)。

根界面使用 BoxWithConstraints 与 `PaneSize`，通过 `LocalPaneSize` 向下传递内容区域宽高。外层窗口先决定是否放侧栏，内部再根据扣除侧栏后的实际内容宽度选择分栏或双页。因此外层刚好 600 dp 时，并不保证内部阅读内容也达到 600 dp。

## 2. 当前断点与宽度

| 用途 | 条件／上限 | 行为 |
| --- | --- | --- |
| 主导航 | 外层宽度 >=600 dp | 80 dp 侧边导航；否则使用底部导航 |
| 详情分栏 | 内容宽度 >=600 dp 且高度 >=480 dp | 信息和章节区域分栏 |
| 紧凑高度 | 内容高度 <480 dp | 使用更紧凑的展示路径 |
| 横向双页 | 内容宽度 >=600 dp、高度 >=360 dp、偏好开启、非纵向模式 | 封面单页，之后连续配对 |
| 主页面最大内容宽 | 1200 dp | 避免超宽屏内容无限拉伸 |
| 主设置最大内容宽 | 720 dp | 控制表单阅读宽度 |
| 阅读页面最大内容宽 | 2400 dp | 允许大屏阅读空间 |
| 纵向漫画默认列宽 | 最大 720 dp | 居中单列，缩放在默认宽度基础上计算 |

这里的数值是代码布局约束，不是厂商设备规格。dp 与物理像素的换算受系统逻辑密度影响；安全区、侧栏、工具栏还会进一步减少内容空间。

网格使用自适应列宽与跨全列条目，而不是固定“手机两列、平板四列”。筛选栏、分区标题等通过 `fullItem` 占满当前网格列数，避免误放进单个漫画卡片格。

## 3. 折叠与阅读位置

稳定身份是原始图片索引。双页状态只是一个展示映射：封面索引 0 单独一组，之后 1–2、3–4 配对。宽度变化时，先确定原页所在组；恢复单页时仍以原页为准，而不是用双页组号当页码。

例如外屏读到 UI 第 3 页，展开后显示第 2–3 页这一组，收起应继续停在第 3 页。日漫从右向左模式只调整翻页方向与组内视觉顺序，不把数据库中的页码反向编码。

Activity 配置变化时 ViewModel 与 Compose 状态恢复机制共同保留当前会话。进程被杀后的持久恢复依赖 Store 的章节与页码，不承诺恢复整个导航栈、页面滚动像素、目录弹窗或当前缩放。

## 5. 主题与字体

[Theme.kt](../app/src/main/java/com/arnolee/moye/Theme.kt) 定义固定 Material 3 色板。浅色以纸张米白和松绿为主，深色以深墨绿和浅绿文字强调为主。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| background / surface | `#F6F5EF` | `#141B17` |
| primary | `#356653` | `#B4D4BA` |
| onSurface | `#252E28` | `#E5E9DE` |
| secondary | `#9A7446` | `#D6B98B` |

设置值为 system、light、dark。system 使用 `isSystemInDarkTheme()`；状态栏和导航栏图标明暗也随主题更新。没有使用系统壁纸动态取色或用户自定义色板。

字体采用系统字体；headlineLarge 使用 Serif、32 sp、40 sp 行高，正文 bodyLarge 为 16 sp、26 sp 行高。内容主要为中文，图片漫画不随主题反色。深色模式改变界面背景，不改写原始漫画图片。

## 6. 阅读界面的布局约束

恢复默认尺寸按钮与页码栏占用独立布局区域，漫画视口在自己的边界内裁切，避免按钮覆盖漫画内容。关闭普通工具栏后，非默认缩放仍应能看到恢复入口。

纵向缩小到 50% 时居中，无需向左右拖动空白；放大后根据实际图片宽度限制横移。缩放改变布局尺寸，不能只靠把整个 LazyColumn 用 graphicsLayer 放大，否则页边界、滚动范围与点击坐标会不一致。具体锚点算法见 [06](06-阅读器与手势实现.md)。

横向双页模式仍按组布局。连续滚动不自动变成双列，避免长条漫画阅读顺序混乱。

## 7. 品牌资源

应用显示名称是 ComicReader，当前图标是 **构成主义风格的抽象漫画书**。早期风格探索不代表当前交付资源。原稿与生成说明位于 [assets/branding](../assets/branding/)，Android 启动器资源位于 [res](../app/src/main/res/)。

使用 adaptive icon 时，需要同时检查圆形、圆角方形等系统裁切；前景安全区和背景色不能只在原始正方形 PNG 上验收。修改图标不应顺带更改包名、签名或数据库目录。

## 8. 可用性检查清单

- 按外屏、内屏、横屏、窄分屏分别检查标题换行、筛选项和底栏。
- 长漫画名、长章节名、错误文本不应推走主要操作。
- 深色主题下正文、次级说明、禁用态和进度条应可分辨。
- 系统字体放大后，按钮文字不应被裁切；该项需要额外人工验收，不能仅凭当前截图宣称全面通过。
- 阅读模式切换后验证方向、单双页映射和恢复默认按钮。
- 触摸区域与图标内容描述应持续审查；现有 Compose 语义测试标签不等于完整 TalkBack 无障碍验收。
- 数据加载、空列表、错误重试与已有内容并存时都需要可理解的状态，不能只设计有网络、有数据的成功页面。

## 9. 未来适配方向

尚未实现的方向包括：铰链遮挡避让、半折布局、实体 One UI 连续性专项测试、大字体与 TalkBack 全流程验证。应先取得设备或模拟能力、建立可复现测试，再把结果写成已支持能力。
