# 05 · 书架、详情与阅读历史

[返回文档中心](README.md) · 基线：1.3.4

## 1. 三种相关但独立的状态

收藏是 books.favorite；历史是 progress；下载是 downloads 与磁盘文件。收藏一本书不会自动下载，阅读一本未收藏的书也会保留历史，删除下载不会删除收藏或进度。

书架有“我的收藏”和“最近阅读”两个视图。顶部继续阅读卡片取所有书中最近的记录，不要求该书已收藏。最近阅读列表按漫画合并，每部漫画只显示其最新一条章节记录。

## 2. 详情加载与本地回退

openBook 先取消之前的详情与阅读任务，从 store.book 查本地完整书籍；没有时使用进入页面时携带的卡片。页面可以先展示已知标题和封面，再请求最新目录。成功 putBook 并更新 selected；失败时，若本地已有章节，显示“当前使用已保存的目录”，仍允许从本地目录进入。

putBook 保护一个重要不变量：搜索／榜单卡片通常没有完整章节，不能覆盖数据库里已有的完整目录。传入 chapters 为空且旧记录存在时，保留旧对象。带完整章节的新详情则替换 data，但 favorite 通过 SQL 更新语句保留。

## 3. 详情页操作

- 收藏／取消收藏：确保书籍存在后翻转 favorite。
- 开始／继续阅读：read(book)，使用本书最新进度；无历史使用目录第一章。
- 点击具体章节：read(book, chapter)，恢复该章自己的页码。
- 正序／倒序：仅改变详情中的展示顺序，不改变 stored chapters 的逻辑阅读顺序。
- 批量下载：以章节 ID 列表保存当前选择；提交时从原书目录过滤，避免重复的 UI 排序改变下载顺序。
- 本书阅读记录：按该书所有已读章的最近时间展示，可点击继续指定章。
- 刷新目录：重新 openBook，失败仍可使用已有目录。

宽屏时详情左右分栏，左侧简介与主要动作、右侧章节网格；窄屏或低高度时纵向排列。布局不改变这些业务语义。

## 4. 逐章进度模型

progress 主键为 `(book, chapter)`。同一数字章节 ID 即便出现在不同漫画中，也不能互相覆盖。记录字段含章节标题、0 基页码、总页数和毫秒时间戳。

saveProgress 只接受 total > 0 且 page 在 `[0,total)` 内的值，以 INSERT OR REPLACE 更新。它保存的是“本章最近一次读到的位置”，不是整章所有访问事件。因此“本书阅读记录”不是逐页浏览日志，也没有访问次数统计。

### 写入时机

- 竖向模式的 firstVisibleItemIndex 变化时。
- 横向模式的 settledPage 改变并需要更新规范单页时。
- 页码滑块跳转完成时。
- 目录／按钮切章、离开阅读及生命周期 ON_PAUSE／onDispose 的保存路径。
- 末页额外滑动切章前，明确保存该章最后一张原始图片索引；章首向后切章前保存本章第 0 页，并打开上一章末页。按钮和目录切章仍恢复目标章原有历史。

recordPage 会比较捕获的 ChapterPages 与当前 selected／activeChapter，避免旧阅读内容销毁时写回到另一部漫画或另一章。它同时触发当前窗口的预加载调度，但预加载不会反过来写入 progress。

## 5. 两种历史查询

### 最近的一章

progress(book, chapter=null) 按 `time DESC, rowid DESC` 取一条。rowid 是时间相同情况下的确定性排序补充，不是对用户展示的业务 ID。

### 每本漫画一条

history 使用相关子查询，从每个 book 中选最新的 rowid，再按 time 倒序排列。若两本书的记录时间完全相同，其跨书展示次序没有额外业务顺序保证；已修复的是同一本书内部最近章节的确定性。

chapterHistory(book) 则返回该书所有章的最后记录，按 time 和 rowid 倒序，供详情弹层使用。

## 6. 恢复规则与案例

| 场景 | 结果 |
| --- | --- |
| A 书第 3 章读到索引 7，打开 B 书 | A 的记录仍为第 3 章第 8 页 |
| A 第 4 章以前读到索引 2，再从第 3 章切入 | 恢复第 4 章第 3 页，不强制从首页开始 |
| 第一次打开某一章 | 索引 0 |
| 源站更新后该章页数变少 | 恢复时将旧页码限制在新清单有效范围 |
| 下载或预取下一章完成，但尚未打开 | 不新增该章阅读记录 |
| 删除已下载章节 | 仍可看到以前读到哪里；未有缓存的图片需联网 |
| 卸载或清除应用数据 | 数据库、偏好与私有下载文件会丢失 |

阅读位置精确到原始图片页，不保存竖向页内像素偏移、缩放倍率、横向拖动位置或跨设备状态。设备旋转／展开保留规范页索引，不应写入双页组号。

## 7. 改动约束

不能把 history 简化成一个全局 lastChapter；不能只用 chapterId 查进度；不能把所有 SELECT 排序都去掉 rowid 补充；不能在下载删除路径删 books/progress；也不能为了数据“干净”而升级时清库。相关测试见 LibraryTest、ChapterAdvanceTest、FoldLayoutTest。
