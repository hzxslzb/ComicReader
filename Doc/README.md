## 文档、代码与发布的关系

- 根目录 [README](../README.md)：项目展示、下载与快速构建入口。
- `Doc/`：持续维护的详细技术文档；本次新增内容集中放在这里，注意目录首字母大写。
- 原有 [实现概览](../docs/IMPLEMENTATION.md)：保留兼容入口，详细说明以本目录为准。
- [历史发布公告](../docs/releases/)：对应已发布版本的说明，不因新增文档而改写已发布 APK。
- [TESTING.md](../TESTING.md)：按版本记录实际跑过的验证；不能把“有测试代码”当成“本次已执行”。

应用名称为 ComicReader，但正式包名、部分类名和本地签名文件名仍包含 `moye`。这是为了保留早期“墨页”版本的身份与覆盖升级能力，不应仅为统一名称就修改包名或私有数据路径。

## 图与校验工具

架构正文包含 GitHub 可渲染的 Mermaid 图；[architecture.drawio](diagrams/architecture.drawio) 提供可编辑组件图。本次没有导出 PNG，原因是编写环境未安装 draw.io 桌面 CLI；`.drawio` 可直接用 draw.io / diagrams.net 打开。

校验工具只使用 Python 标准库，建议 Python 3.10 或更高版本；构建 Android App 本身不依赖 Python。在仓库根目录执行：

```sh
python3 Doc/tools/check_docs.py
```

工具检查本目录及相关根文档的本地链接、Markdown 代码围栏、标题、图文件结构。它不访问外网，不验证远程站点是否可用，也不代替人工核对代码语义。

## 更新约定

1. 改动用户行为时，同步更新功能文档和对应实现章节。
2. 改表结构或偏好字段时，更新 09；数据库迁移必须先实现再写成“已支持”。
3. 改网络、缓存或预加载时，更新 04、07、11，并补对应测试。
4. 改读屏断点、缩放和手势时，更新 06、10、13。
5. 发布时更新版本基线、CHANGELOG、发布公告和实际测试证据。
6. 文档中的源码链接使用相对路径，不依赖某台开发机的绝对路径，不记录签名密码或用户私有数据。
