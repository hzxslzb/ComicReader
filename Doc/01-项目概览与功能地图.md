# 01 · 项目概览与功能地图

[返回文档中心](README.md) · 基线：1.3.4

## 1. 产品定位

ComicReader 是 Android 原生漫画阅读器。它读取漫画柜移动站的公开页面数据，在 Compose 界面呈现书目、章节和图片；不嵌入网页阅读器，不执行数据源 JavaScript，也不加载网页广告组件。章节图片本身包含的水印、版权页或宣传页不会被裁切或去除。

它适合搜索、追更、收藏、在线阅读和预先下载后离线阅读。App 无自建后端、无应用账号、无跨设备同步；数据源仍是外部网站，不能承诺所有漫画始终可访问。

## 2. 产品导航

主导航显示顺序为：**发现 → 书架 → 搜索 → 下载 → 设置**。内部编号分别为 `4 / 0 / 1 / 2 / 3`，编号不等于视觉位置。默认进入发现页。漫画详情和阅读器位于主导航之上，返回阅读器会先回详情，再回主页。

### 2.1 功能矩阵

| 功能 | 用户操作与结果 | 主要实现 | 联网要求 |
| --- | --- | --- | --- |
| 首页热门 | 查看横幅和栏目、换一批、打开作品 | DiscoverScreen / DiscoverSource | 需要联网获取，当前会话可保留结果 |

| 搜索 | 关键词、历史词、分页或粘贴链接 | AppViewModel.search | 新搜索需要联网 |
| 收藏 | 详情页加入／取消书架收藏 | LibraryStore.toggleFavorite | 已保存作品不需要联网 |
| 最近阅读 | 每本漫画一条最近章节及页码 | LibraryStore.history | 本地可用 |

| 深浅主题 | 浅色、深色、跟随系统 | MoyeTheme | 本地偏好 |
| 折叠屏 | 网格、分栏、侧栏、单双页自适应 | PaneSize / ReaderSpreads | 无额外联网要求 |

## 3. 从搜索到离线阅读的完整路径

1. 在搜索页输入关键词；结果并不限于初始演示作品《脑洞学生会》。可搜范围取决于源站搜索结果。
2. 打开作品详情，先显示已保存卡片／目录，再请求最新详情。
3. 点击收藏，把该作品标记为书架收藏；收藏不自动创建下载。
4. 点击开始／继续阅读；App 先选上次章节，没有历史则选目录第一章。
5. 浏览图片，自动保存当前漫画的当前章页码；读取清单或预加载本身不生成阅读历史。
6. 从目录切章或在末页再向前滑动时，目标章已有记录则恢复断点；章首再向后滑动会返回上一章末页。
7. 在详情批量选择章节下载，或在阅读器下载当前章。
8. 等下载完成后断网，从书架、详情或下载页再次进入该章，使用私有目录内的完整图片。

“读过一章”和“完成下载”是两件事：读过的图片可能只在临时缓存中，缓存会被淘汰，不能用作稳定的离线承诺。

## 4. 设置默认值

| 设置 | 默认 | 可选值 | 保存位置 |
| --- | --- | --- | --- |
| 主题 | 跟随系统 | system / light / dark | settings SharedPreferences |
| 阅读方向 | 上下滚动 | vertical / ltr / rtl | 同上 |
| 宽屏自动双页 | 开启 | 开／关 | 同上 |
| 预加载 | 开启 | 开／关 | 同上 |
| 预加载页数 | 5 页 | 3 / 4 / 5 | 同上 |
| 仅 Wi-Fi 预加载 | 开启 | 开／关 | 同上 |

预加载选项在主设置和阅读设置中共用同一份状态。切换即时作用于后台预取；“仅 Wi-Fi”不会禁止用户用移动网络打开当前章节，也不约束显式的离线下载任务。

## 5. 术语

| 术语 | 含义 |
| --- | --- |
| 漫画／book／manga | 一部作品，使用源站数字 ID |
| 章节／chapter | 一组图片，标识必须和漫画 ID 一起使用 |
| 页码／page | 内部从 0 开始的图片索引；界面显示时加 1 |
| 清单／manifest | ChapterPages：路径、签名查询参数、上下章 ID 等 |
| 双页组／spread | 横向阅读的一组图片，不是历史记录的计数单位 |
| 临时缓存 | Coil 保存的可淘汰图片，不等于离线下载 |
| 预加载／preload | 为未来阅读提前获取清单和图片，不写阅读进度 |
| 下载完成 | 下载任务完整落盘；可从永久章节目录读取 |
| 断点 | 每本漫画、每章保存的最后页码；不包括页内像素偏移 |

## 6. 当前没有的能力

没有多数据源插件、登录、评论、云同步、数据导入导出、定时自动追更、自动安装更新、跨设备阅读记录同步、章节图片编辑及页内精确位置恢复。横向阅读仍是 1–4 倍缩放；本轮 50% 下限针对上下滚动模式。
