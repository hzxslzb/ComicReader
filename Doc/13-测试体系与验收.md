# 13 · 测试体系与验收

[返回文档中心](README.md) · 实际执行记录：[TESTING.md](../TESTING.md)

## 1. 分层与证据规则

项目使用 JVM 测试验证纯解析、映射和请求协调，用 Android instrumentation 测试验证数据库、真实 Compose 手势、窗口变化和端到端流程。部分设备测试依赖真实站点，因此网络、站点结构、系统权限弹窗都会影响结果。

本文描述当前测试体系与验收方法；某个方法存在于仓库，不代表最近一次版本发布已运行它。每次发布应在 TESTING.md 单独记录运行命令、环境、结果和未覆盖项。文档补全不会重新生成应用测试结果。

## 4. 运行方式

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug
```

单独选择某个 JVM 测试类：

```sh
./gradlew :app:testDebugUnitTest --tests com.arnolee.moye.ReaderLoadingTest
```

**设备测试仅在专用模拟器／测试设备运行**。它们会修改显示尺寸、网络开关和测试应用数据，不能在用户正在使用的正式设备上无准备地执行。

```sh
adb devices
./gradlew :app:connectedDebugAndroidTest
```

仅运行一个类：

```sh
./gradlew :app:connectedDebugAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.class=com.arnolee.moye.PreloadPreferencesTest
```

报告通常位于 `app/build/reports/tests/`、`app/build/reports/androidTests/` 和 `app/build/reports/lint-results-debug.html`；具体文件路径以 Gradle 本次输出为准。保留失败阶段及完整异常，但公开前移除私有数据。

## 5. 测试环境陷阱

### 通知弹窗

Android 13+ 首次启动可能弹出通知授权。弹窗会挡住 Compose 页面，使点击、可见性和截图断言失败。PreloadPreferencesTest 通过规则在 Activity 创建前授予测试包通知权限。新增用例要先控制授权状态，不应把弹窗遮挡误判为业务失败。

### 网络切换异步

调用关闭 Wi-Fi／数据命令后，默认网络回调和旧请求结束不是同步发生的。测试必须等待实际断网，再断言离线行为。否则可能出现“离线成功”实际仍用了尚未断开的连接。

### 手势识别等待

单击与双击存在识别窗口，不能在点击后立即认定工具栏状态已经稳定。章节末页切换还要求先停稳、释放前一次手势，再开始新的向前滑动。

### 真实站点漂移

作品标题、页数、分类数量和排行榜内容可能变化。固定的解析夹具应保持可解释；在线流程应报告所用公开作品／章节和时间。如果站点响应被挑战页替代，先诊断环境，不要随意把解析空结果认作正常结束。

## 6. 功能验收矩阵

| 功能 | 正向验收 | 反向／边界验收 |
| --- | --- | --- |
| 搜索 | 多结果、历史、打开链接 | 空输入、无结果、错误链接、失败重试 |
| 发现 | 分类、排序、加载更多 | 切筛选不串列表、断网保留旧内容、空末页 |
| 收藏与历史 | 两本书分别续读、同书多章记录 | 同章节 ID 不串书、取消收藏不清历史 |
| 在线阅读 | 三种模式、目录、跳页、上下章 | 快速连续切章、旧响应晚到、无下一章 |
| 末页切章 | 稳定末页再主动向前滑动 | 到末页的同次手势、惯性、短拖、反向拖、双指不触发 |
| 缩放 | 50%、100%、400%、双击和按钮复位 | 小于默认居中、放大横移边界、按钮不盖漫画 |
| 预加载 | 开关、3/4/5 页、跨章补齐 | Wi-Fi 丢失、前台共享不取消、预取不写历史 |
| 下载 | 单章／多章、进度、暂停继续 | 删除竞态、断网、空间不足、损坏响应 |
| 离线 | 完整章节无网阅读和续读 | 缺一页、仅有临时缓存、文件损坏不误称完整保证 |
| 折叠屏 | 外内屏、横屏、单双页映射 | 低高度、窄分屏、重建不漂移页码 |
| 升级 | 旧数据覆盖安装后保留 | 错误签名拒绝、数据库迁移遗漏 |

矩阵包含应执行的验收项，不表示每一项都有自动化或已经在所有系统上执行。特别是磁盘不足、长期队列、低内存和真机厂商行为仍需补充覆盖。

## 7. 新改动应选择哪些测试

- 改解析：对应 JVM 夹具测试，加一次代表性实站流程。
- 改预加载、取消或切章：ReaderLoadingTest、ChapterNetworkTest、ChapterLoadingTest、PreloadPreferencesTest，必要时 ChapterAdvanceTest。
- 改缩放／布局：ReaderZoomTest、AdaptiveTest、ReaderZoomFlowTest、FoldLayoutTest。
- 改数据库或下载：LibraryTest、ReadingFlowTest，并补相关迁移／原子提交边界。
- 只改品牌文案／图标：构建及相关界面检查；不必无原因反复跑全部联网测试。
- 只改文档：运行文档工具和 diff 检查，人工核对代码，不伪造新的应用测试结果。

## 9. 当前验证边界

实际设备流程主要在 Android 16 / API 36 模拟器验证，minSdk=26 只是配置支持下限，不意味着 API 26 真机已经全面验证。Fold7 使用比例模拟，尚无实体设备测试。真实章节下载样本规模有限，不能声称所有作品、所有 CDN、所有章节都验证通过。

后续优先补充：API 26 和 targetSdk 对应系统、实体 Fold7、长图低内存、下载删除竞态与磁盘不足、进程终止恢复、数据迁移夹具。每次新增覆盖都应留下可重复的步骤和实际结果。
